BrightROI Logo Suite

Includes transparent-background SVG source files and PNG exports where rendering was available.

Variants:
- Full lockup: icon + wordmark
- Icon only: gradient and solid contrast versions
- Wordmark only: color and high-contrast versions
- Light/dark contrast lockups

Palette:
- Deep navy: #071329
- Electric blue: #2563EB / #087BFF
- Cyan: #06B6D4 / #16B8FF
- Violet: #8B5CF6 / #9B4DFF
- Light: #F8FAFC

Note: These files are a clean vector recreation inspired by the approved Concept 10 reference, not an extraction of the original generated pixels. Text uses a system sans-serif font stack; convert text to outlines in a vector editor before sending to a print vendor if exact typography consistency is required.
